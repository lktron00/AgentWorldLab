# Recorded synthetic example

This is a sanitized recording of the real GPT-6 Luna validation run on
2026-10-25: two seeds, six calls and US$0.0004773 estimated model usage.
Provider/call IDs were replaced; usage counts, prices, outcomes and public
decision justifications are retained. Original artifact hashes and the
validation summary are in `docs/ai-validation.json`. No native engine
checkpoint files, credentials or internal model reasoning are included.

Rebuild the standalone report with `python3 scripts/build-example-report.py`.
This command makes no API calls and does not rerun the simulation. Rendering
these files does not constitute a new live model execution.
